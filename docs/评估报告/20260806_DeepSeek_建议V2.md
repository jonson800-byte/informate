## DeepSeek V2 总体评估

**结论：可行性较高（约 75%），具备进入设计和 MVP 开发的决策条件。**

| 维度 | 可行性 | 关键依据与风险 |
|:--|:--|:--|
| 产品-市场匹配 | **较高** | 企业 AI 焦虑真实存在，¥3000-30000/年价格带被验证；"不用搭的 AI 工作台"可避开 Coze 等搭建型平台 |
| 技术可行性 | **中等偏高** | 核心组件已有验证或明确 API；风险在规模扩展，混合路线已预留 |
| 商业模式 | **中等** | 开通费+积分计费清晰，毛利率 30% 可覆盖；冷启动期需价格让利换客户和数据 |
| 护城河 | **中等（需运营加固）** | 跨客户聚合闭环竞品未做透，但纯技术壁垒低，必须靠运营深度+客户关系+先发数据 |
| 团队 | 依赖配置 | MVP 阶段至少：1 全栈（Node.js/React）+ 1 AI 工程师（Hermes/Agent）+ 1 产品/行业运营 |

## 关键优化建议（比 V1 更具体）

### 1. 产品
- **MVP 砍到 2 个场景**（工作助手 + 生成图片；视频做首批付费客户**增购项**，不放首次体验流）
- 产出物面板增加：**"复制到剪贴板/下载" + "加入企业资产库"** 按钮（资产库作为后续企业级产出物管理的钩子）
- **预置 3 套行业知识包**（医美/装修/电商代运营）：MVP 前人工整理术语/FAQ/常用模板，灌入 Obsidian → 首批客户"开箱即懂行"，弥补数据积累前空白

### 2. 技术
- **MVP 暂不实现"每租户每场景独立 profile"**：<20 租户用"场景模板 profile + 按租户隔离 Hindsight bank + 会话级 system prompt 注入行业信息"；>20 租户再按 C 路线实例化
- **积分系统"异步扣费 + 补偿"模式**：发起→校验→**冻结（预留）**→异步执行→成功实扣/失败解冻；关系型 DB 事务
- **知识库存储**：Postgres + pgvector，每 bank 一个 schema，表 `(id, content, embedding, metadata{type:术语/FAQ/..}, industry, scene)`；检索按租户行业确定 bank 列表并行检索按权重合并
- **管理后台尽早规划**：简易管理后台（租户开通/场景分配/积分查询充值/会话查看），避免早期全靠改数据库

### 3. 商业模式
- **首次体验：0 元开通费 + 赠送 500 积分**（功能受限：生图带水印、会话次数限制）→ 降低获客阻力
- **提前设计"行业高级版"包装**：明确告知后续有"医美行业增强包/装修增强包"，定价在场景年费基础上溢价 50-100%；数据贡献客户给永久折扣
- **积分阶梯包**：100元=1100积分（赠10%）、500元=6000积分（赠20%）、2000元=25000积分（赠25%）→ 鼓励预充值改善现金流

### 4. 运营与护城河
- **Obsidian 人工层立即平行启动**：开发同时手动搭建 3 个行业知识库（术语/FAQ/话术/模板/法规），作为种子数据
- **知识飞轮质检轻量化**：初期"通过/拒绝 + 打标签"简单流程，一个人每周 2 小时即可
- **利用竞品知识库反哺**：参考 Coze/文心智能体平台公开行业 Bot 设定，提炼行业常见问题与术语

## 分阶段实施步骤（🆕 新增，V1 没有）

### 阶段 0：启动与准备（2 周）
- 团队组建（全栈/AI 工程师/产品运营各 1）
- 设计冻结：MVP 2 场景、场景包 Schema、API/DB Schema
- 基础设施：云服务器、模型 API（DeepSeek/火山方舟/MiniMax）、域名、CI/CD
- **种子知识生产**：3 个行业各至少 50 条术语 + 20 个 FAQ + 3 个话术模板，脚本入库
- 复验资产：M1 合规引擎可运行、Seedream/H3 API 调通

### 阶段 1：MVP 开发（6-8 周）
- 后端：Node.js API（租户/会话/场景路由）、Hermes 模板化创建（工作助手/生图模板）、三层 bank 检索注入、积分系统（充值/冻结/扣费/解冻）、任务管理（异步生图/失败退分/状态回调）
- 前端：三栏布局（场景列表/Chat 流式/产出物面板）
- 简易管理后台 + 联调安全（合规引擎、鉴权、脱敏）+ 内部验收（10 张图、多轮会话、知识注入效果）

### 阶段 2：封闭测试（4-6 周）
- 3-5 家友好客户免费试用 3 个月（签署试用协议，明确数据使用与隐私条款）
- **知识飞轮 v0.5**：周提取客户独立 bank 高频对话 → 手工脱敏 → 整理进行业 bank → 观察回复质量变化
- 商业模式验证：测试"如果收费 X 元/月你会继续用吗"的接受度
- 视频作为增购项接入

### 阶段 3：公开发布（持续 3 个月）
- 正式发布，首批 10-20 付费客户
- 行业知识包独立上线（加价售卖"专业版"）
- 运营团队扩编（1 名行业运营）+ 聚合脚本 v1 正式化（人工审核台确认后入库）
- C 路线改造（模板化动态创建 + 数据隔离层）

### 阶段 4：规模化（6 个月后）
- 每行业 50+ 客户 → 发布垂类 Agent 高级版（主力盈利点）
- 合规能力产品化（M1 合规引擎包装为独立增购服务）
- 生态建设：开放场景包定义，合作伙伴上传行业场景包，平台分成
