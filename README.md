# Informate · 企业 AI 能力平台

> B端AI赋能平台 — 让企业用 AI 干活。
> 一句话定义：**场景化 Chat 工作台**。企业开通账号、充值积分，在对话里使用 AI 能力，产出物自动展示，所有能力按积分计费。

## 核心定位

- **形态**：Web 页面，三栏布局（左侧场景列表 / 中间 Chat 主窗口 / 右侧产出物面板）
- **本质**：Chat 驱动的多 Agent 聚合页面，按客户需求场景化开放
- **计费**：¥500/场景/年开通费 + 积分消耗（1元 = 10积分，按场景单价）
- **后端**：Node.js API + Hermes profile 引擎（服务端 Pipeline），每租户每场景独立 agent
- **模型**：deepseek（文本）+ Seedance / minimax h3（多模态）
